# 平台下发设备控制命令（草案）

> 状态：待设备端与后端确认，尚未开发，尚未发布到 ShowDoc。

## 1. 功能说明

平台通过设备的命令 WebSocket 向头盔下发控制命令。设备收到命令后，先返回接收确认，再在执行结束后返回执行结果。

- WebSocket：`ws://{server}/{sn}/cmd`
- 数据格式：JSON 文本
- 下发方向：平台 → 设备
- 结果方向：设备 → 平台

控制命令使用 `cmd_id` 进行关联。现有的 `msgid` 继续用于设备主动上报，不作为平台控制命令的标识。

## 2. 平台下发命令

```json
{
  "cmd_id": "cmd-20261010-000001",
  "cmd": "snap_jpeg",
  "params": {}
}
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `cmd_id` | string | 是 | 平台生成的命令唯一标识 |
| `cmd` | string | 是 | 命令名称 |
| `params` | object | 否 | 命令参数；没有参数时可传空对象 |

第一阶段拟支持以下命令：

| `cmd` | 说明 |
| --- | --- |
| `start_pcm` | 开始录音 |
| `stop_pcm` | 停止录音并上传录音文件 |
| `snap_jpeg` | 拍照并上传图片 |
| `get_status` | 查询设备当前运行状态 |

录像、重启等控制命令暂不纳入第一阶段。

`get_status` 成功时，设备在执行结果中返回基本状态：

```json
{
  "cmd": "command_result",
  "cmd_id": "cmd-20261010-000002",
  "request_cmd": "get_status",
  "status": "success",
  "data": {
    "device_state": "idle",
    "recording": false,
    "playing": false,
    "network": "connected",
    "uptime_seconds": 3600,
    "app_version": "2026.10.10"
  }
}
```

## 3. 设备接收确认

设备收到命令并完成格式及当前状态检查后，立即返回确认。

接受执行：

```json
{
  "cmd": "command_ack",
  "cmd_id": "cmd-20261010-000001",
  "status": "accepted"
}
```

拒绝执行：

```json
{
  "cmd": "command_ack",
  "cmd_id": "cmd-20261010-000001",
  "status": "rejected",
  "error_code": "DEVICE_BUSY",
  "message": "设备正在执行其他操作"
}
```

`accepted` 只表示设备已经接受命令，不表示操作已经完成。

## 4. 设备执行结果

执行成功：

```json
{
  "cmd": "command_result",
  "cmd_id": "cmd-20261010-000001",
  "request_cmd": "snap_jpeg",
  "status": "success"
}
```

执行失败：

```json
{
  "cmd": "command_result",
  "cmd_id": "cmd-20261010-000001",
  "request_cmd": "snap_jpeg",
  "status": "failed",
  "error_code": "EXECUTION_FAILED",
  "message": "拍照失败"
}
```

建议的基础错误码：

| 错误码 | 说明 |
| --- | --- |
| `INVALID_COMMAND` | 命令格式或必要参数错误 |
| `UNSUPPORTED_COMMAND` | 设备不支持该命令 |
| `DEVICE_BUSY` | 设备当前无法接受新的操作 |
| `EXECUTION_FAILED` | 设备执行失败 |

## 5. 文件上传关联

设备由控制命令触发录音或拍照时，在原有文件上传事件中增加相同的 `cmd_id`：

```json
{
  "msgid": 127,
  "cmd_id": "cmd-20261010-000001",
  "cmd": "upload_jpeg",
  "file": "rv1126b-1760083201.jpeg",
  "msg": "success"
}
```

- `msgid`：设备主动消息的序号，保持现有协议兼容。
- `cmd_id`：产生该文件的控制命令标识。
- 由头盔实体按键触发的上传事件不携带 `cmd_id`。
