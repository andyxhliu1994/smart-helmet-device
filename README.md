# 智能头盔设备端

本仓库保存 RV1126B 智能安全头盔的设备端 C 工程及部署文件。

## 当前能力

- 采集 16 kHz、16-bit、单声道 PCM 录音
- 拍摄 JPEG、录制 H.264 视频
- 通过 HTTP 上传音频、图片和视频文件
- 通过 WebSocket 与后端交换控制消息
- 接收后端返回的 PCM 语音并通过头盔扬声器播放
- 支持 RTSP、RTMP 及本地按键事件

## 主要入口

- `main.c`：程序入口及各模块初始化
- `common/common.c`：配置、录制文件及上传通知
- `lwsc/lwsc.c`：命令与语音 WebSocket 客户端
- `httpc/httpc.c`：HTTP 文件上传
- `ai/ai.c`：麦克风采集
- `ao/ao.c`：扬声器播放
- `key/key.c`：实体按键处理
- `install/oem/helmet/`：设备部署文件示例

## 交接基线

首次提交来自项目交接源码副本，并与检查时设备上运行的可执行文件校验一致，作为后续维护的原始基线。

设备配置中包含历史测试服务地址，部署前应按实际环境检查并更新。
